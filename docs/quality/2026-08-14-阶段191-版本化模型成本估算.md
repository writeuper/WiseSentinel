# 阶段191：版本化模型成本估算

## 面试缺口

平台已经观测 prompt/completion/total Token，但 Token 不是金额。若没有绑定 provider/model 的价格版本，直接输出成本会产生无法审计的数字。

## 实现

`scripts/report_agent_quality_metrics.py` 支持 `--pricing-profile PATH` 或 `MODEL_PRICING_PROFILE_FILE`：

```json
{
  "profile": "provider-model-2026-08",
  "currency": "USD",
  "prompt_usd_per_1k": 0.15,
  "completion_usd_per_1k": 0.60
}
```

通过校验后报告输出 prompt/completion/total 成本、占比和每次模型生成平均成本，并附价格文件 SHA-256 指纹。报告不输出文件路径、密钥或请求明细。

## Fail-closed 口径

- 未配置价格文件：`model_cost.status=not_claimed`，金额为 `N/A`。
- JSON、币种、profile 名称或价格为负数/非有限数：`invalid`，不估算金额。
- 成本仅是观测 Token × 价格 profile 的离线估算，不含工具、RAG、基础设施、折扣、缓存和税费。
- Token usage 缺失时，估算只反映已有供应商 usage 样本，不能外推整段生产流量。

当前仓库未提供真实 provider 价格文件，因此本地默认报告仍为 `not_claimed`，没有虚构成本数字。
