# 阶段 178：模型 Token 用量可观测性

## 背景

面试中提出了模型成本、容量和预算指标缺口。平台已有模型延迟、准入和熔断指标，但 OpenAI 兼容响应中的 token usage 尚未进入 Prometheus，无法估算 token 预算或分析长尾请求的输入/输出规模。

## 实现

- 新增 `ws_model_tokens_total` Counter。
- 标签仅包含受控 `provider`、`operation`（`generate`/`stream_handshake`/`stream_complete`）和 `token_type`（`prompt`/`completion`/`total`）。
- 同步 Generate 解析并记录 `prompt_tokens`、`completion_tokens`、`total_tokens`。
- 缺失、零值或负值 usage 不写入指标；不记录模型名、租户、Prompt、URL 或密钥。
- 增加模型响应 usage 保留和指标采集回归测试。

## 当前边界

流式响应的完整 usage chunk 解析尚未接入，当前不能声称 SSE token 成本完整覆盖；后续需确认供应商 `stream_options.include_usage` 契约后再补充。Token 数量也不是金额，生产成本还需要按固定 provider/model pricing profile 离线计算，避免把价格写入高基数指标。
