# 阶段188：Citation 独立证据校验

## 目标

补充 Citation 结构校验之外的 grounding 检查，确认回答中的 `doc_id` 是否出现在独立持久化 Trace 的工具证据中，避免把模型或 HTTP 响应自带的 Citation 当成检索真实性证明。

## 实现范围

- 仅从 Trace step 的 `output_summary`、`output`、`evidence`、`detail` 字段提取文档证据；支持对象、列表和 JSON 字符串中的 `doc_id`、`documents`、`citations`、`evidence`。
- 评测结果新增 `citation_grounded`，聚合指标新增 `citation_grounding_rate`、`citation_grounded`、`citation_grounding_total`。
- Trace 没有独立文档证据时返回 `N/A`（分母为 0），不输出 0% 或 100%，也不把文档 ID写入汇总报告。

## 验收结论

- Citation 与 Trace 证据匹配：按有效 Citation 文档数统计 grounded 数量。
- Citation 与 Trace 证据不匹配：计入未 grounded。
- 无独立 Trace 证据：不可验证，指标为 `N/A`。
- 单元测试覆盖上述三类场景，且通过现有评测回归测试。

## 当前可信度边界

该指标只证明 Citation 与已持久化 Trace 证据的一致性，不能替代人工相关性标注、Recall/MRR/nDCG 或真实数据源可用性证明。若 Trace 只记录摘要而未持久化文档 ID，必须保持 `N/A`，不得据此宣称 Citation 有效率。
