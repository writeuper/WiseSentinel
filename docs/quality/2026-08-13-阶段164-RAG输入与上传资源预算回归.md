# 阶段 164：RAG 输入与上传资源预算回归

## 修复

### Retriever 输入边界

- `MilvusRetriever.Retrieve(nil)` 现在返回稳定错误，不再 panic。
- Retriever 缺少 Milvus client 或 Embedder 时均返回稳定错误。
- 这样可以防止 Worker、内部 Agent 或测试 Harness 绕过 HTTP schema 后触发进程级异常。

### 上传资源预算

上传接口此前主要依赖 multipart `File.Size` 判断 50MB 限制；该字段属于不可信元数据，恶意或异常客户端可能声明较小 Size、实际发送更大内容，导致 `io.ReadAll` 无界读取。

现改为 `io.LimitReader(reader, maxUploadBytes+1)`，在读取阶段强制预算，超过上限立即拒绝；恰好达到上限的内容仍接受。
