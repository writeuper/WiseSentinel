# 阶段 119：Agent 平均耗时与并发复测

## 目标

补充 Agent 请求平均耗时的可复现分析，并在真实 HTTP 链路上复测低并发 Chat 的端到端延迟、成功率和测试资源清理，区分集成环境观测值与生产 SLO。

## 数据来源与口径

- 聚合脚本：`scripts/report_agent_quality_metrics.py`，统计当前服务生命周期内已持久化 Trace；
- 并发脚本：`scripts/run_concurrent_chat_load.py`，4 个隔离 Chat 请求、并发度 2；
- 平均耗时包含 API 接入、Agent 编排、模型/工具/RAG 等端到端处理；不是单独模型首 token 延迟；
- RAG P95 仍按 Histogram 桶上界解释，不将其表述为精确百分位。

## 结果

### 生命周期聚合

| 维度 | 样本/结果 |
|---|---:|
| 成功/完成 Trace | 1535 |
| 终态失败 Trace | 73 |
| 成功 Agent 平均耗时 | 7349.83 ms（约 7.35 s） |
| 全部终态平均耗时 | 7553.63 ms（约 7.55 s） |
| Chat 平均耗时（全部） | 13166.44 ms（约 13.17 s） |
| Ops 平均耗时（全部） | 3171.54 ms（约 3.17 s） |
| 平均 Trace 步数 | 3.100 |

Chat 长于 Ops，主要由上游模型生成和长尾超时驱动；Ops 在受控工具链路中平均更短，但失败样本平均耗时显著升高，符合重试/超时路径特征。

### 本轮真实 HTTP 并发复测

- 请求数/并发度：4/2；
- 成功率：4/4（100%）；
- P50：9178 ms；P95：10711 ms；最大：10711 ms；
- 模型准入拒绝：0；
- 测试资源清理：4/4；
- 质量门禁：通过。

## 结论

当前开发/集成环境可将普通 Chat 的低并发端到端平均耗时暂记为约 9–13 秒：生命周期聚合约 13.17 秒，本轮并发 2 的 P50 为 9.18 秒。该范围受模型供应商、网络、提示词长度、RAG/工具路径和历史失败样本影响，不能直接作为生产 SLA。

建议生产前按 Chat、Ops、RAG、SSE TTFT 分开建立 P50/P95/P99 基线，并在 1/2/5/10/20 并发阶梯下记录 429、504、admission wait、工具失败、Trace 完整率、连接池和队列指标。
