# 阶段 173：Ops 任务终态错误传播

## 发现

Ops Agent 在模型/工具链失败时曾忽略 `FinishIfOwned`、任务读取和 `RetryOrFailIfOwned` 的错误及 CAS 结果；成功结果持久化失败或执行租约丢失也可能只返回泛化错误。数据库异常时任务可能长期保持 `running`，完成率、失败率和平均耗时指标因此失真。

## 修复

- 超时/不可重试失败：检查终态写入错误和 owned CAS 结果。
- 可重试失败：检查任务读取、重试/失败转换错误和状态变更结果。
- 成功写入失败或租约丢失：更新 Trace 失败状态并返回明确错误/冲突。
- 保留执行令牌围栏，不允许旧 worker 覆盖新 owner 的任务。

## 影响与剩余风险

异步 Ops 的任务完成率、失败率和耗时统计不再把数据库写入异常误归类为成功或悬挂。数据库完全不可写时仍无法立即落库，需依赖恢复后的 running-task 巡检；本轮未改变既有租约和回收策略。
