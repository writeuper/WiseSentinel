## 指标口径说明

RAG Histogram 只测检索阶段，不等于 Agent 端到端耗时。本轮 RAG-001 端到端约 19.7 秒，而当前 RAG 检索样本均值约 228.563 ms、P95 为 1000 ms Histogram 桶上界；主要差异来自模型生成和 Agent 编排长尾。评测和生产仪表盘必须同时展示检索耗时、模型耗时、工具耗时和端到端耗时。
