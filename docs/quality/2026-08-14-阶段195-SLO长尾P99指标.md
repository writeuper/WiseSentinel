# 阶段195：SLO 长尾 P99 指标

## 面试缺口

仅有平均值、P50/P95 无法覆盖企业 Agent 的长尾体验和错误预算。尤其是模型、RAG 与工具出现少量长尾时，平均值会掩盖容量或依赖退化。

## 实现

质量报告在以下层级补充 P99：

- Agent Trace：success、business terminal、all finished；
- Tool：全量和成功样本；
- RAG retrieval：成功样本 histogram P99；
- Model generation：成功样本 histogram P99。

当 histogram 的 P99 落在 `+Inf` 或没有样本时输出 `N/A`，并保留 bucket upper-bound 语义；不把 `+Inf` 强行转换成最后一个有限桶。

## 口径边界

P99 是长尾观测指标，不自动等价于生产 SLO。生产错误预算还需要按 Chat/Ops/SSE、模型 profile、租户 cohort、工具/RAG 依赖和时间窗口分桶，并结合真实生产 Attestation 与业务成功事件。
