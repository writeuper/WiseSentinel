# 阶段 143：模型熔断半开并发与可观测性

## 修复

模型熔断器在 30 秒恢复窗口进入 half-open 时，原实现可能允许多个并发请求同时作为探针，形成上游探针风暴。本阶段新增共享状态 `breakerProbeInFlight`：

- 仅第一个请求获得 half-open probe；
- 其他并发请求收到稳定的 probe-in-flight 错误；
- 探针成功关闭熔断并清零失败计数；
- 探针失败继续保持失败状态并重新计时。

## 新增指标

```text
ws_model_breaker_events_total{provider="...",event="open|rejected|probe|closed"}
```

Provider 只使用受控分类（如 `openai`、`other`），不包含模型名、URL、租户、凭证或错误原文。

## 验证

- 新增 half-open 单探针单测；
- 新增熔断事件低基数标签测试；
- 模型和可观测性包测试通过；
- 真实 130 条评测中模型超时仍独立统计，不与业务质量混淆；
- 现有 SSE cancel/delete-race、RAG integration 和全量门禁继续通过。
