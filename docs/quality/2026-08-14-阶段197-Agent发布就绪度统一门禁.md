# 阶段197：Agent 发布就绪度统一门禁

## 面试缺口

平台已有评测覆盖、质量聚合、生产流量 Attestation 和 SLO 报告，但它们彼此独立。没有统一门禁时，容易只看到“130 Case”或“工具成功率”就误判平台已经具备生产发布证据。

## 实现

新增 `scripts/check_agent_release_readiness.py`，组合三个脱敏 JSON 产物：

- 评测集 coverage：数量、结构和断言覆盖；
- Agent evaluation summary：业务通过率和 verified RAG 样本数；
- quality aggregate：生产流量 Attestation 和 SLO/error budget 状态。

可选开启 `--require-production` 和 `--require-slo`，任何缺失、非法或不满足门槛的证据都会 fail-closed，并输出 blocker 名称，不输出模型原文、Prompt、Trace ID、租户 ID或密钥。

## 当前真实门禁结果

本地运行结果：

- Case coverage：130 条，结构门禁通过；
- Agent evaluation summary：当前没有可用 summary artifact；
- production traffic：`not_claimed`；
- SLO：`not_claimed`；
- 综合状态：`not_ready`，阻塞项为 `agent_eval`、`production_traffic`、`slo_error_budget`。

这说明平台具备可执行的发布证据门禁，但当前环境仍不能宣称生产就绪。

## 使用

```bash
python3 scripts/check_agent_release_readiness.py \
  --coverage artifacts/eval-coverage.json \
  --evaluation artifacts/eval-summary.json \
  --quality artifacts/quality-aggregate.json \
  --require-production --require-slo
```
