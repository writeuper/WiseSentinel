# 阶段192：真实业务反馈闭环指标

## 面试缺口

平台已有知识卡片反馈接口，但此前质量报告没有统计用户是否认为答案/知识/工具结果有用，无法把 Agent 技术指标与业务反馈区分开。

## 实现

质量报告新增匿名反馈聚合：

- 总反馈、有效评分数、有用数、无用数和未知评分数；
- `useful_rate = useful / (useful + bad)`；
- 按 `fault_knowledge`、`answer`、`tool_call` 和 `other` 分组；
- 全量和最近 24 小时窗口。

查询只读取目标类型与 rating，不读取反馈 ID、目标 ID、用户 ID或评论内容。

## 可信度口径

- 没有反馈样本时有效率为 `N/A`，不能当成 0% 或 100%。
- 反馈是自选样本，存在响应偏差，不能替代 100+ Case 的人工 Gold 评测、Recall/MRR/nDCG 或生产业务成功事件。
- 当前本地数据库没有反馈记录，因此报告为 `total=0`、`useful_rate=N/A`；未虚构真实用户满意度。
