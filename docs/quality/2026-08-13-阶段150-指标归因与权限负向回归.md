# 阶段 150：指标归因与权限负向回归

## 指标归因核验

- SSE 取消场景产生 `ws_model_calls_total{operation="stream_complete",outcome="canceled"}`，未计入成功调用。
- SSE 过载保护产生 `ws_model_calls_total{operation="stream_handshake",outcome="overloaded"}`，与业务失败和正常 stream completion 分离。
- 取消、过载和成功分别具备独立的 `model_call_duration_seconds` 分桶，可用于计算真实上游长尾和准入拒绝率。
- 本次取消回归结束后，模型指标显示 canceled 与 success 分开计数；没有将客户端取消误报为成功。

## 权限负向验证

- 开发 API Key 访问 `GET /api/v1/approvals` 返回 HTTP 403、业务码 40301；operator 不能读取管理员审批队列。
- 跨租户 Trace 请求伪造 `X-Tenant-ID` 返回 404/40401，JWT/API Key 身份中的租户边界优先于请求头。

## 真实用户链路汇总

- Trace 所有者读取、SSE 基础/取消/删除竞态、同步 Chat 幂等和同 key 并发均通过。
- 4 路 SSE 并发为 3 次成功、1 次 50304 准入保护；该保护事件单独归因，不混入业务失败率。

## 结论

当前模型、Trace、审批和租户指标已经能区分：业务成功、客户端取消、上游过载、权限拒绝和资源不存在。生产看板应继续按 `operation/outcome` 分桶，并将 50304、403、404 与 Agent 业务失败独立展示。
