# 阶段193：评测集覆盖与标注可信度

## 实现

新增 `scripts/report_eval_dataset_coverage.py`，对 CSV 评测集做离线结构审计：

- Case 总量与 100+ 规模门禁；
- Chat/Ops 路由和场景分布；
- 工具正向命中、禁止工具负向用例和工具覆盖；
- source/keyword/knowledge/tool 断言丰富度；
- relevance 标注数量、verified 数量及覆盖率；
- 重复 Case ID、缺失输入和缺失路由。

## 当前 130 Case 事实

运行默认评测集得到：

- 130 条 Case，规模门禁通过；
- Chat 45、Ops 85；
- 11 类场景；
- 105 条包含 expected tool，25 条包含 forbidden tool；
- 130 条有至少一个结构断言；
- relevance 标注 0 条、verified 0 条，覆盖率 0%。

因此可以可信地说明“评测集规模与结构覆盖达标”，但仍不能宣称 RAG Recall@K、MRR、nDCG 已经有可信结果；这些指标必须在双人复核 Gold 集完成后再报告。

## 使用

```bash
python3 scripts/report_eval_dataset_coverage.py \
  --input docs/整理与提升/enterprise_agent_eval_cases_130.csv \
  --format markdown
```

该工具只读取 CSV 元数据和断言字段，不调用模型、不读取密钥、不输出用户/租户信息。
