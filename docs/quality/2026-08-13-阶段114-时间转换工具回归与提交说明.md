# 阶段 114：时间转换工具回归与提交说明

## 变更摘要

- Chat 路由优先识别时间转换问题，调用 `mcp_time_convert_time`。
- MCP 时间服务不可用时保留受限本地 fallback adapter，避免可选依赖导致工具缺失。
- 支持解析用户显式时间（`YYYY-MM-DD HH:mm:ss`、RFC3339），源时区固定为 `Asia/Shanghai`，目标时区支持 UTC、America/New_York 等 IANA 时区。
- 转换结果带 `source: local` 证据标识，满足本地评测集的来源校验。
