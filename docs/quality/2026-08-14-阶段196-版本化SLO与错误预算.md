# 阶段196：版本化 SLO 与错误预算

## 面试缺口

报告已经有 Trace 成功率和 P95/P99，但没有版本化目标，因此不能回答当前运行是否消耗完错误预算，也不能把观测数据与发布门禁关联。

## 实现

支持 `--slo-profile` 或 `AGENT_SLO_PROFILE_FILE`，配置示例：

```json
{
  "profile": "agent-slo-2026-08",
  "success_rate_target": 0.99,
  "p95_latency_ms": 5000,
  "p99_latency_ms": 10000
}
```

报告基于已完成的 business terminal Trace 计算：成功率、允许失败数、错误预算剩余、预算消耗比例，以及 P95/P99 是否达标。SLO profile 也带 SHA-256 指纹，便于发布审计。

## Fail-closed 口径

- 未配置 profile：`slo.status=not_claimed`。
- profile 非法或没有任何延迟目标：`invalid`。
- 没有 business terminal 样本：`not_available`。
- `abandoned` Trace 不进入业务成功/失败分母；它单独作为恢复信号报告。
- 错误预算评估只说明当前观测窗口相对目标的状态，不代表生产 SLO；生产结论仍需按 Agent 类型、模型、租户和时间窗分桶，并绑定真实生产 Attestation。
