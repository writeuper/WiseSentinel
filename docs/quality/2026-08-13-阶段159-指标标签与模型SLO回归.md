# 阶段 159：指标标签与模型 SLO 回归

## 指标安全修复

- HTTP method 标签现在仅允许 `GET/POST/PUT/PATCH/DELETE/HEAD/OPTIONS`，其他值统一为 `OTHER`。
- Ops 延迟 histogram 的 `stage` 仅允许 `queue/run/e2e`，`status` 仅允许已定义任务终态/中间态，未知值统一为 `other`。
- 新增归一化单测，防止自定义 method、未知状态或扩展流程输入制造 Prometheus 高基数。

## SLO 告警补充

在既有 HTTP、工具、RAG、Ops 告警基础上新增：

- `WiseSentinelModelFailureRate`：模型 timeout、overloaded、upstream_error 超过 10%。
- `WiseSentinelModelAdmissionRejections`：本地模型准入拒绝率超过 5%。

告警仅使用 provider/operation/outcome 等既有受控标签，不包含部署名、租户、Prompt 或上游错误正文。
