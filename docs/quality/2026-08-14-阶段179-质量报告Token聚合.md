# 阶段 179：质量报告 Token 聚合

## 背景

阶段 178 已把同步/流式模型 usage 写入 `ws_model_tokens_total`，但质量聚合报告尚未解析该指标。没有聚合层，运营人员仍需手工读取 Prometheus，无法将 token 用量与 Agent 延迟、准入拒绝和失败率放在同一份报告中。

## 实现

`scripts/report_agent_quality_metrics.py` 新增 `model_tokens` 聚合：

- prompt、completion、total token 总量；
- 按 operation 的 token 汇总；
- 是否存在 usage 样本；
- 输入/输出 token 比值（completion 为 0 时为 `N/A`）。

只接受受控 operation 和 token_type 标签，忽略未知标签；不计算金额，不把 provider/model 原始值输出到报告。

## 验证

- 新增 token Prometheus 文本解析单测。
- Python 自动化测试：57/57 通过（全量门禁以提交时结果为准）。

## 可信度边界

Token 计数仍依赖供应商返回 usage；缺 usage 时报告为零/无样本。金额需由外部、版本化的 pricing profile 离线计算，不能从当前指标直接推断成本。
