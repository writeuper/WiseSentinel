# WiseSentinel 质量治理与迭代记录

本目录是 WiseSentinel 的质量治理事实来源。每个迭代阶段单独保存一份 Markdown，记录：需求和风险、测试范围及证据、问题根因、企业级可选方案与取舍、落地修改、回归结果、遗留风险及下一阶段门禁。

## 质量门禁

| 层级 | 命令/证据 | 适用范围 |
| --- | --- | --- |
| 后端单元测试 | `make test` | 每次 Go 代码变更 |
| 前端类型与生产构建 | `make typecheck-frontend` | 每次 Portal 变更 |
| 离线工程门禁 | `make verify` | 合并前 |
| RAG MySQL/Milvus 集成测试 | `make test-integration OPS_TEST_MYSQL_DSN=...` | 修改知识库、向量检索、RAG 删除或代际状态后 |
| RAG 标注排序评测 | `make rag-eval OPS_TEST_MYSQL_DSN=...` | 修改嵌入、向量检索、排序或召回阈值后 |
| 真实场景与并发门禁 | `make test-real-scenarios OPS_TEST_MYSQL_DSN=... OPS_TEST_REDIS_ADDR=...` | 合并前，或修改 RAG、任务、审批、限流、租约后 |
| Ops 租约/CAS 集成测试 | `make test-ops-integration OPS_TEST_MYSQL_DSN=... OPS_TEST_REDIS_ADDR=...` | 修改任务状态机、Worker 或 Redis 租约后 |
| 审批过期/CAS 集成测试 | `make test-approval-integration OPS_TEST_MYSQL_DSN=...` | 修改审批状态与授权决策后 |
| 索引租约/CAS 集成测试 | `make test-index-integration OPS_TEST_MYSQL_DSN=... OPS_TEST_REDIS_ADDR=...` | 修改 Index Worker、索引状态机或 Redis 租约后 |
| 在线 Agent 冒烟评测 | `make agent-eval-smoke EVAL_BASE_URL=http://127.0.0.1:8090/api/v1 EVAL_API_KEY=...` | 部署到集成环境后 |
| 专项安全/可靠性回归 | 对应阶段文档中列出的测试 | 涉及身份、租户、工具、RAG、任务和审批的变更 |
| 敏感数据脱敏回归 | `go test ./internal/pkg/redact ./internal/toolkit` | 修改日志、Trace、工具证据、Ops/Chat API 或持久化投影后 |
| API/Trace/脱敏边界回归 | `make test-boundaries` | 修改请求入口、Trace、审核意见、权限或观测投影后 |

在线 Agent 评测会调用真实服务和测试租户；必须在隔离环境执行，禁止指向生产租户或使用生产凭据。

## 角色协作

| 角色 | 核心职责 | 阶段产出 |
| --- | --- | --- |
| Agent 架构师 | 边界、SLO、风险模型、技术选型与验收设计 | 架构决策、风险台账、阶段门禁 |
| Golang 后端工程师 | 服务、状态机、权限、工具、数据与可观测性实现 | 最小修复、后端回归测试、迁移说明 |
| 前端工程师 | Agent 交互、流式状态、审批、可访问性与前端权限体验 | 组件/E2E 回归、用户可见验证 |
| 自动化测试工程师 | 分层测试、评测集、质量门禁、缺陷闭环 | 测试矩阵、结果、缺陷与回归证据 |

任何阶段不得以删除断言、跳过用例、吞掉错误、绕过鉴权或弱化审批作为“修复”。
