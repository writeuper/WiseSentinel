# 阶段 111：边界、安全、并发回归与请求契约修复

## 结论

本阶段针对企业级 Agent 平台的请求边界、身份租户、幂等、SSE、并发、RAG 一致性、敏感输出和前后端构建进行了回归。发现并修复了请求校验错误被错误映射为 HTTP 500、以及空白问题绕过必填校验两个缺陷。

## 修复内容

- `internal/gateway/middleware/response.go`
  - 识别 GoFrame validation error，统一返回 HTTP `400`、业务码 `40001` 和稳定消息“参数校验失败”。
  - 不再把 `The Question field is required` 等框架内部文本暴露给客户端。
- `internal/gateway/handler/validation.go`
  - 对标题、Chat 问题、Ops 查询和审批评论执行 TrimSpace 非空校验，同时保留 Unicode rune 长度限制。
- 新增对应单测，覆盖 GoFrame 校验错误、任意上游错误隔离、空字符串、ASCII 空白、制表/换行和全角空格。
