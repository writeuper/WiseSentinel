# 阶段 87：共享模型并发 Race 门禁

日期：2026-08-11

## 背景

阶段 81–84 引入共享模型运行态、共享 admission channel、熔断状态与 Stream release 路径。这些机制即使普通单测通过，仍可能存在 map、锁、channel 或 goroutine 的数据竞态。

## 结果

```bash
go test -race ./internal/model ./internal/agent/chat ./internal/agent/ops -count=1
```

Model、Chat、Ops 三个核心并发路径均通过 race detector，未报告数据竞争。

## 边界

race detector 覆盖的是当前测试实际执行到的路径，不证明外部供应商网络、多进程、多副本、数据库 worker 或所有业务交错完全无竞争。发布前仍应保留真实 SSE 容量、取消、Ops worker 与集成环境并发回归。
