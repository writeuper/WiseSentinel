## 评测分类修复

全量 Chat 评测曾将业务错误 `HTTP 504 / code 50401 / 模型服务响应超时` 归类为 `http_error`。这会错误指向鉴权或接口问题。评测器现在将 `50401`、中文“超时”和英文 timeout 统一归类为 `timeout`，并保持 429 优先归类为 `rate_limited`。新增单元测试覆盖两种分类优先级。
