# 企业级告警排查 Runbook 知识资产

本目录提供可供 WiseSentinel RAG 检索的脱敏运维手册，覆盖容器、服务、数据库、中间件、网关、发布和节点资源等常见故障。

## 文档规范

- 每份文档独立描述适用范围、现象、排查顺序、处置、验证、升级和证据要求，便于按标题切 Chunk。
- 所有命令、指标、服务名和时间窗均为示例，不代表真实生产数据。
- 不写入 API Key、Token、密码、连接串、真实租户标识、用户数据或生产地址。
- 高风险动作仅描述审批前提和安全边界，不执行删除数据、关闭鉴权或全局关闭保护措施。

## 覆盖主题

CrashLoopBackOff、OOMKilled、HTTP 5xx、P95 延迟、Redis 超时/连接池、MySQL 死锁、Kafka lag、网关 429、发布回滚、节点资源压力。
