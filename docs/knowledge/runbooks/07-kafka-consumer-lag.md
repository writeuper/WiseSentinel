# Kafka Consumer Lag 排查 Runbook

## 适用范围

适用于消费组 lag 持续增长、消息处理延迟或重平衡频繁。

## 排查顺序

1. 按 topic、partition、consumer group 查看 lag、生产/消费速率和最老消息年龄。
2. 检查消费者错误、处理耗时、批量大小、线程数、重试和死信量。
3. 检查 broker 磁盘、网络、ISR、分区热点及最近扩缩容/发布。
4. 关联下游数据库、缓存和外部依赖的限流或超时。
5. 判断是生产突增、消费变慢、分区倾斜还是消费组不稳定。

## 处置

先保护下游容量，再按审批扩容消费者或降低生产速率；对毒消息设置有界重试并转入死信。禁止无验证地跳过消息或删除 topic。

## 验证与升级

lag、最老消息年龄、消费错误率和重平衡恢复，关键消息业务校验通过后结束事件。消息丢失、顺序性或重复消费影响资金/订单时升级。

## 证据

lag 曲线、生产消费速率、partition 分布、消费者日志摘要、重试/死信、下游依赖指标和处置记录。
